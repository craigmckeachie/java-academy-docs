# Mac Quickstart

New to a Mac, or just want to get around faster? Start here.

## Shortcuts you'll use every day

On a Mac, **⌘ Command** does most of what **Ctrl** does on Windows.

| Shortcut | What it does |
|---|---|
| **⌘ Space** | Spotlight: search for and open any app or file (try typing "IntelliJ") |
| **⌘ Tab** | Switch between open apps |
| **⌘ C** / **⌘ V** / **⌘ X** | Copy / paste / cut |
| **⌘ Z** / **⌘ Shift Z** | Undo / redo |
| **⌘ A** | Select all |
| **⌘ F** | Find on the page or in the file |
| **⌘ S** | Save |
| **⌘ W** / **⌘ Q** | Close the window / **quit** the app (closing a window doesn't quit it) |
| **⌘ Shift 4** | Screenshot part of the screen (saved to your Desktop) |
| **⌘ Shift .** | Show or hide hidden files in Finder (files that start with `.`, like `.gitignore`) |
| **Control ⌘ Space** | Emoji and symbol picker |
