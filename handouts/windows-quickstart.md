# Windows Quickstart

New to Windows, or just want to get around faster? Start here.

## Shortcuts you'll use every day

| Shortcut | What it does |
|---|---|
| **Windows key**, then type | Search for and open any app or file (try typing "IntelliJ") |
| **Alt Tab** | Switch between open windows |
| **Ctrl C** / **Ctrl V** / **Ctrl X** | Copy / paste / cut |
| **Ctrl Z** / **Ctrl Y** | Undo / redo |
| **Ctrl A** | Select all |
| **Ctrl F** | Find on the page or in the file |
| **Ctrl S** | Save |
| **Windows E** | Open File Explorer |
| **Windows Shift S** | Screenshot part of the screen (copied to the clipboard) |
| **Windows V** | Clipboard history: paste something you copied earlier |
| **Windows D** | Show the desktop |
| **Ctrl Shift Esc** | Task Manager: close a program that's frozen |

> [!TIP] Show file extensions
> In File Explorer, choose **View → Show → File name extensions**, so you can see that a file is `App.java` and not just `App`.
