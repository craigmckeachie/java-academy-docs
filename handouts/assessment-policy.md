# Assessment Policy: What "Open Book" Means

The assessments are **open book**: you may use the resources below while you take them. Anything not on this list is off-limits.

## Can reference

- [W3 Schools Java](https://www.w3schools.com/java/default.asp)
- [Java Documentation](https://docs.oracle.com/en/java/javase/17/)
- [Java Programming MOOC](https://java-programming.mooc.fi/part-1)
- [Java Spring Documentation](https://docs.spring.io/spring-framework/reference/index.html)
- [Java Spring Boot Documentation](https://docs.spring.io/spring-boot/index.html)
- [W3 Schools SQL](https://www.w3schools.com/sql/default.asp)
- [W3 Schools SQL Quick Reference](https://www.w3schools.com/SQl/sql_quickref.asp)
- [MySQL Reference Manual](https://dev.mysql.com/doc/refman/8.4/en/)
- Workbooks on Brightspace
- Code on GitHub (your code, your classmates' code, and your instructor's code)
- IntelliJ or MySQL Workbench, to test out code and syntax
- Your written or typed notes

## Cannot reference (DO NOT USE)

- **AI chatbots**, including but not limited to OpenAI ChatGPT, Google Gemini, Anthropic Claude, and GitHub Copilot
- **Search engines** (Google, Bing, etc.) and the links they return, unless the site is listed above
