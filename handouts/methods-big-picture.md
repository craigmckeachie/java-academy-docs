# Methods: Big Picture

| Methods… | When |
|---|---|
| **Are verbs** | Today |
| **Are tasks being done on your behalf**<br>• sometimes it is easier to do things yourself<br>• but if you have too many things to do, it helps to break the task into smaller tasks<br>• and if you do the same things over and over, delegating them is useful<br>• methods aren't only about reuse; they **reduce complexity** | Today |
| **Can give you back something** when completed (`return`)<br>**OR give you back nothing** (`void`) | Today |
| **Can require inputs** to do the task (**parameters**) | Today |
| **Can be organized together** (in classes) | Today (lightly) |
| **Some tasks you can use right away:** `Class.doSomething()` (`static`) | Preview |
| **Other tasks need some setup first:**<br>`Class object = new Class();`<br>`object.doSomething();` | Later: Workbook 2a |
| **Can be used inside the class** where they're defined (`private`)<br>**OR outside it** (`public`) | Later: Workbook 2a |

*Focus on **Today**. Preview and Later are a sneak peek.*
